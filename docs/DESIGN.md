# 网络连通性监测小工具 —— 总体设计说明

> 技术栈：.NET 8 + WPF，MVVM + 依赖注入 + 后台调度
> 主窗口形态：单窗口 + 多页导航；桌面工具条为独立窗口
>
> 本文档只描述结构与行为，不涉及代码实现细节，是行为定义的唯一依据。

---

## 一、目标与范围

周期性检测目标 IP 连通性，可选检测指定端口，记录结果，提供状态标识、历史查询、CSV 导出、连续失败告警、告警历史、桌面工具条、开机自启与单实例运行。

## 二、总体架构分层

### 1. 表现层（Views）

- 主窗口（单窗口多页导航）：仪表盘页、日志页、告警历史页、设置页、关于页
- 桌面工具条窗口（独立、可拖动、置顶可选）
- 托盘图标与托盘菜单
- 告警弹窗

### 2. 视图模型层（ViewModels）

- 主窗口壳视图模型：导航、当前页、全局状态
- 仪表盘 / 日志 / 告警历史 / 设置 / 关于 各页视图模型
- 工具条视图模型
- 命令集：启动、停止、暂停、恢复、导出、清空、保存设置、导航等

### 3. 服务层（Services）

- 连通性检测服务：Ping + 端口检测
- 调度服务：周期触发，支持启动/暂停/恢复/停止
- 持久化服务：检测记录、告警记录、配置存取
- 清理服务：按保留天数清理历史
- 导出服务：CSV 导出
- 告警服务：连续失败计数与触发、告警记录写入
- 窗口形态服务：主窗口/工具条/托盘切换，位置记忆
- 单实例服务：互斥检测与激活已有实例
- 自启动服务：开机自启注册/取消

### 4. 模型层（Models）

- 监测配置、检测记录、告警记录、检测状态枚举、告警配置、界面配置

### 5. 基础设施

- 依赖注入容器、配置文件读写、全局异常处理、状态→颜色转换器

## 三、主窗口与导航结构

### 1. 窗口形态

- 单窗口，左侧导航栏 + 右侧内容区
- 导航项：仪表盘、日志、告警历史、设置、关于
- 底部或顶栏显示全局当前状态标识（与各页状态含义一致）

### 2. 页面跳转

- 仪表盘可跳转日志页（查看全部）
- 工具条恢复主窗口时，默认回到上次停留页；无记录则回仪表盘
- 运行中切换页面不影响检测（调度与页面解耦）

### 3. 关闭主窗口行为（设置项，默认"转为工具条"）

- 可选值：退出程序 / 最小化到托盘 / 转为工具条
- 默认为"转为工具条"
- 退出程序的入口：主窗口菜单、托盘菜单、工具条右键菜单
- 关闭行为在设置页配置，保存后生效

### 4. 托盘

- 托盘图标常驻，菜单项：显示主窗口、转为工具条、暂停/恢复、退出
- 托盘通知用于告警（可选开关）

## 四、页面划分与职责

### 1. 仪表盘页

- 当前状态大标识（颜色+文字）
- 目标 IP、端口、检测间隔摘要
- 最近一次检测时间、延迟、连续失败次数
- 快捷操作：启动、停止、暂停、恢复、转为工具条
- 最近若干条记录简表（只读预览，可跳转日志页）
- 不放置详细配置与导出操作

### 2. 日志页

- 完整检测记录表格：时间、目标IP、Ping结果、延迟、端口结果、整体状态、错误摘要
- 筛选：按状态、按时间范围
- 排序；数据量大时启用虚拟化
- 操作：导出CSV、清空（清界面与删历史为同一操作）、打开日志目录
- 清空操作需二次确认，执行后同时清空界面集合与数据库历史记录
- 显示"当前保留 N 天，早于某日期的记录将被自动清理"提示

### 3. 告警历史页

- 独立页面，展示历次告警记录
- 字段：告警时间、目标IP、端口、连续失败次数、最近失败原因摘要、告警方式
- 支持按时间范围筛选、导出CSV（可选）、清空（需确认）
- 与检测日志分表存储

### 4. 设置页

- 分组展示，避免单页过长：
  - a) 目标设置：IP、端口（可空）
  - b) 检测设置：间隔（时/分/秒）、超时、端口检测策略
  - c) 告警设置：连续失败阈值、告警方式（弹窗/托盘通知）、是否将端口失败单独计入
  - d) 存储设置：历史保留天数、内存最大条数、数据目录（可选自定义，默认为用户目录）
  - e) 界面设置：关闭主窗口行为（退出/托盘/工具条，默认工具条）、工具条是否置顶、最小化是否自动转工具条
  - f) 启动设置：开机自启开关
- 底部：保存、恢复默认、取消
- 保存后生效（见第五节生效策略）
- 校验失败在页内行内提示，不弹窗打断
- 有未保存修改时切换页面或关闭窗口，提示确认

### 5. 关于页

- 版本、配置文件与数据库位置、日志目录、使用说明入口

## 五、配置与生效策略

### 1. 配置持久化

- 配置项保存到本地配置文件，存于用户目录，随用户账户迁移
- 启动时读取并回填界面；无配置时使用默认值
- 配置文件含版本号，后续新增字段做兼容处理（缺失取默认值）

### 2. 生效策略（统一为"保存后生效"）

- 设置页修改后点击保存才生效，取消不生效
- 运行中保存配置：
  - 目标IP、端口、间隔、超时、端口检测策略：保存后按新配置重启调度周期
  - 告警阈值、告警方式、端口失败计入规则：保存后立即用于后续判断
  - 保留天数：保存后下次清理按新值执行
  - 数据目录：保存后先迁移已有数据再切换（见第十一节），失败则保持原目录并提示
  - 界面设置、开机自启：保存后立即应用
- 保存时校验：IP格式、端口范围、间隔大于0、保留天数合法、阈值大于0

## 六、核心流程

### 1. 启动检测

- 校验配置
- 加载保留期内历史记录与告警记录
- 冷启动计数延续：读取最近连续失败次数，若已达阈值，启动后按告警规则处理（可能立即告警，见第八节）
- 启动调度，进入运行状态

### 2. 单次检测流程

- Ping 检测，记录结果与延迟
- 按端口检测策略决定是否检测端口
- 汇总检测记录
- 写入内存集合（受最大条数限制）
- 写入持久化存储
- 交告警服务判断连续失败
- 刷新仪表盘、工具条、托盘状态

### 3. 暂停 / 恢复 / 停止

- 暂停：停止计时与检测，保留配置、记录、连续失败计数与告警状态；状态显示"暂停中"
- 恢复：按原间隔继续，连续失败计数延续
- 停止：结束调度，回到未运行状态；连续失败计数保留至下次启动

### 4. 清空日志

- 二次确认后，同时清空界面集合与数据库检测记录
- 告警历史不受影响，需在告警历史页单独清空

## 七、端口检测策略

可选策略：

1. 始终检测：无论 Ping 结果都检测端口
2. 仅 Ping 成功时检测：Ping 失败则端口记为"未检测"
3. 仅 Ping 失败时检测：用于判断主机不通还是 ICMP 被禁
4. 不检测：即使配置端口也不检测

端口结果三态：成功 / 失败 / 未检测，界面与导出均体现。

## 八、连续失败告警

### 1. 失败判定

- 以整体状态为准，非成功计一次失败
- 可配置是否将"端口失败"单独计入（默认计入）

### 2. 计数规则

- 连续失败累加，成功一次清零
- 暂停期间不计数、不告警

### 3. 冷启动延续

- 启动时读取历史中最近连续失败次数并延续
- 若已达阈值，启动后按告警规则处理，可能立即触发告警

### 4. 触发与重置

- 连续失败达到阈值触发一次告警，进入"已告警"状态避免重复弹窗
- 恢复成功一次后重置告警状态与计数

### 5. 告警方式与内容

- 应用内弹窗、托盘通知（可配置）
- 内容：目标IP、端口、连续失败次数、最近失败时间与原因摘要
- 工具条状态变红并显示"告警中"

### 6. 告警记录

- 每次触发写入告警历史表，供告警历史页查看
- 告警记录字段见第四节告警历史页

## 九、桌面工具条

### 1. 切换方式

- 主窗口按钮、关闭主窗口（默认行为）、托盘菜单

### 2. 形态

- 无边框、可置顶（可配置）、半透明可选、尺寸紧凑
- 显示：目标IP、状态色块、最近延迟、连续失败次数
- 按钮：启动、停止、暂停、恢复、恢复主窗口
- 右键菜单：启动/停止、暂停/恢复、恢复主窗口、退出

### 3. 移动与位置记忆

- 按住拖动移动，退出时保存坐标，下次启动恢复
- 多显示器与分辨率变化时校正到可见区域，防止越界

### 4. 交互

- 双击恢复主窗口，回到上次停留页

## 十、状态标识

- 成功：绿色
- Ping失败：红色
- 端口失败：橙色
- 异常：深红/紫色
- 暂停中：灰色
- 告警中：红色加醒目标记

仪表盘、日志行、工具条、托盘四处含义一致。
暂停中、告警中为界面状态，不写入检测日志；告警写入告警历史。

## 十一、日志与告警历史持久化

### 1. 存储

- 检测记录与告警记录分表存储（本地轻量数据库）
- 每条记录产生后立即写入
- 数据目录可在设置页更改（默认用户目录）：保存后需将已有数据（数据库、日志）迁移至新目录，
  迁移成功前继续使用旧目录；迁移失败保持原路径并提示原因，不丢数据；
  配置文件本身固定存于默认用户目录，不随数据目录迁移，仅记录当前数据目录位置

### 2. 保留天数

- 配置项"保留天数"，默认建议7天或30天
- 启动时清理一次，运行期间定时清理（如每小时）
- 修改保留天数后下次清理按新值生效
- 告警历史保留策略：与检测记录共用保留天数，或单独配置（默认共用）

### 3. 加载

- 启动加载保留期内检测记录与告警记录到界面集合
- 界面展示受"内存最大条数"限制，数据库保留完整保留期内数据供导出

## 十二、CSV导出

### 1. 导出范围

- 日志页：当前筛选结果或全部保留期内数据（可选）
- 告警历史页：告警记录导出（可选功能）

### 2. 格式

- UTF-8 带 BOM，逗号分隔，含字段转义
- 默认文件名含目标IP与时间戳

### 3. 交互

- 保存对话框选择路径，完成后提示条数与路径

## 十三、单实例与开机自启

### 1. 单实例

- 程序启动时检测互斥量，已有实例则激活其主窗口（或工具条）后退出
- 激活行为：显示主窗口并置于前台

### 2. 开机自启

- 设置页开关，写入系统自启动项
- 关闭开关时移除自启动项
- 自启后默认进入工具条形态（可配置，默认工具条）

## 十四、异常与边界处理

1. 配置非法：保存时行内提示，不生效
2. 检测超时/网络异常：捕获记为失败，不中断调度；错误摘要区分超时/不可达/权限等
3. 数据库写入失败：记录保留内存，界面提示持久化异常
4. 导出失败：提示原因
5. 工具条越界：启动与分辨率变化时校正
6. 长时间运行内存增长：内存集合受最大条数限制
7. 全局未捕获异常：提示并写入错误日志，记录位置在关于页可查

## 十五、模块清单

- 模型：监测配置（含数据目录）、检测记录、告警记录、检测状态、告警配置、界面配置
- 服务：连通性检测、调度、持久化、清理、导出、告警、窗口形态、单实例、自启动
- 视图模型：壳视图模型、仪表盘、日志、告警历史、设置、关于、工具条、命令集
- 视图：主窗口（含导航与各页）、工具条窗口、托盘、告警弹窗
- 基础设施：依赖注入、配置读写、全局异常、状态→颜色转换器
