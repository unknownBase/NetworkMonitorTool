# 开发推进计划（DEVELOPMENT_PLAN）

将 [ROADMAP.md](../ROADMAP.md) 的里程碑拆解为可执行的迭代（Sprint），每个迭代以「可构建、可演示」为收口标准。
行为定义以 [docs/DESIGN.md](DESIGN.md)（总体设计说明）为唯一依据，本文件只排顺序、不定细节。

---

## 迭代总览

| 迭代 | 主题 | 对应版本 | 关键产出 | 收口标准 |
| --- | --- | --- | --- | --- |
| S1 | 工程骨架 | v0.1 | 分包、NuGet、泛型主机、DI、全局异常 | `dotnet build` 通过，主窗口经主机启动 |
| S2 | 检测核心 | v0.1 | 检测服务、调度服务、模型、转换器 | 控制台可驱动一轮周期检测并输出结果 |
| S3 | 存储与配置 | v0.1 | SQLite 持久化、appsettings 读写、清理雏形 | 重启后记录与配置不丢 |
| S4 | 页面框架 | v0.1 | 主窗口壳、导航、仪表盘 / 日志 / 设置 / 关于 | 五页可导航，仪表盘展示实时状态 |
| S5 | 日志与导出 | v0.1 | 筛选排序、CSV 导出、清空、内存条数限制 | **v0.1 MVP 演示：完整监测闭环** |
| S6 | 告警引擎 | v0.2 | 连续失败计数、触发去重、冷启动延续 | 断网场景达到阈值恰好告警一次 |
| S7 | 告警展示 | v0.2 | 弹窗、托盘通知、告警历史页、保留清理 | 告警记录可查、可清、可按期清理 |
| S8 | 工具条 | v0.3 | 工具条窗口、拖动、位置记忆、越界校正 | 关闭主窗口转工具条，双击恢复回原页 |
| S9 | 托盘与形态切换 | v0.3 | 托盘菜单、窗口形态服务、关闭行为配置 | 三种关闭行为均正确 |
| S10 | 系统集成 | v0.4 | 单实例、开机自启、端口策略全联动 | 双开仅一实例；自启进工具条 |
| S11 | 加固与发布 | v0.4 | 异常边界、虚拟化压测、文档定稿 | **v1.0 RC：挂机 24h 无泄漏无崩溃** |

> 节奏建议：每个迭代 3~7 个工作日；S5、S7、S9、S11 结束即为可交付演示点。

## 各迭代任务清单

### S1 工程骨架

- [ ] 创建 `Models/ Services/ ViewModels/ Views/ Converters/` 目录并迁移代码
- [ ] 引入 NuGet：`Microsoft.Extensions.Hosting`、`CommunityToolkit.Mvvm`、`WPF-UI`、`Microsoft.Data.Sqlite`
- [ ] App.xaml 接入泛型主机（`Host.CreateDefaultBuilder`），DI 注册占位
- [ ] 全局异常处理：`DispatcherUnhandledException` + `TaskScheduler.UnobservedTaskException` → 写日志并提示
- [ ] `.gitignore`（bin/obj/.vs/*.user/本地数据）、`AssemblyInfo` 版本号

### S2 检测核心

- [ ] `DetectionStatus` 枚举（成功 / Ping失败 / 端口失败 / 异常 / 暂停中 / 告警中）与状态→颜色转换器
- [ ] `PingProbe` + `TcpPortProbe`（超时、错误摘要区分超时/不可达/权限）
- [ ] `IDetectionService`：单次检测编排，端口策略四分支（策略 UI 在 S10 补全，先实现逻辑）
- [ ] `ISchedulerService`：周期触发（间隔时/分/秒），启动/停止/暂停/恢复，与页面解耦

### S3 存储与配置

- [ ] SQLite 建表：`detect_record`、`alert_record`（分表）
- [ ] `IStoreService`：逐条写入、按保留期加载、清空；写入失败降级为仅内存 + 界面提示
- [ ] `MonitorConfig` 等模型 + 配置版本号；`%LOCALAPPDATA%\NetworkMonitorTool\appsettings.json` 读写，缺失字段取默认
- [ ] `ICleanupService`：按保留天数删除过期记录（启动一次 + 每小时）

### S4 页面框架

- [ ] `ShellViewModel`：导航命令、当前页、全局状态、上次停留页记忆
- [ ] 主窗口：左导航 + 右 ContentControl，顶/底栏全局状态标识
- [ ] 仪表盘页 VM：状态大标识、目标摘要、最近检测时间/延迟/连续失败数、快捷操作、简表跳转
- [ ] 设置页 VM：六组配置分区、保存/恢复默认/取消、行内校验、未保存切页确认
- [ ] 关于页 VM：版本、配置/数据库/日志路径

### S5 日志与导出（MVP 收口）

- [ ] 日志页 VM：记录集合（内存最大条数限制）、状态/时间筛选、排序、虚拟化开启
- [ ] `IExportService`：UTF-8 BOM、字段转义、默认文件名含 IP+时间戳、保存对话框、结果提示
- [ ] 清空：二次确认 → 同清界面集合与数据库；页内保留期提示文案
- [ ] 运行中保存配置 → 重启调度周期的生效联动

### S6 告警引擎

- [ ] `IAlertService`：连续失败累加/成功清零、暂停期间不计数、端口失败单独计入开关
- [ ] 阈值触发一次 + 「已告警」去重状态，恢复成功重置
- [ ] 冷启动延续：启动读最近连续失败次数，已达阈值按规则处理

### S7 告警展示

- [ ] 告警弹窗（内容：IP、端口、失败次数、最近失败时间与原因摘要）与托盘通知开关
- [ ] 告警历史页 VM：字段展示、时间筛选、清空确认、导出（可选）
- [ ] 工具条/仪表盘状态「告警中」红色醒目标记接入

### S8 工具条

- [ ] 无边框紧凑窗口：IP、状态色块、最近延迟、连续失败数、五个操作按钮
- [ ] 按住拖动、右键菜单（启动停止/暂停恢复/恢复主窗口/退出）、双击恢复主窗口
- [ ] `IWindowModeService`：主窗口 ↔ 工具条 ↔ 托盘切换；坐标保存恢复；多显示器越界校正

### S9 托盘与形态切换

- [ ] WPF-UI `NotifyIcon`：图标常驻、菜单（显示主窗口/工具条/暂停恢复/退出）
- [ ] 关闭主窗口行为三选项（默认工具条）；最小化自动转工具条开关；置顶开关
- [ ] 退出程序三入口统一走 `Shutdown` 收口（托盘/菜单/右键）

### S10 系统集成

- [ ] `ISingleInstanceService`：Mutex 检测 + 激活已有实例（主窗口或工具条）后退出
- [ ] `IAutoStartService`：HKCU 注册表 Run 项写入/移除；自启后默认工具条形态（可配置）
- [ ] 端口检测策略四选项设置联动与「仅 Ping 失败时检测」场景验证

### S11 加固与发布

- [ ] 边界压测：万级日志行虚拟化、长时间运行内存曲线、DB 锁冲突
- [ ] 分辨率/显示器变化事件校正；导出与自启失败的提示
- [ ] README/CHANGELOG/DESIGN 同步定稿，手测 P0 用例清单，打 v1.0 RC 标签

## 依赖与风险

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| WPF-UI 版本与 .NET 8 兼容矩阵 | S1 阻塞 | S1 首日锁定版本并跑通托盘 Demo |
| ICMP 被禁环境误判 | 告警误报 | S2 即实现端口策略「仅 Ping 失败时检测」兜底 |
| SQLite 单写锁竞争 | 写入失败 | 串行写入队列 + 降级仅内存策略（S3） |
| 工具条位置在多显示器拔掉后越界 | 窗口不可见 | 启动与 `DisplaySettingsChanged` 双时机校正（S8/S11） |
| 开机自启路径含空格 | 自启失败 | 注册表值加引号，S10 覆盖用例 |

## 完成定义（DoD）

1. `dotnet build -c Release` 通过且无新增警告。
2. 行为与 DESIGN 文档对应章节逐条对得上，冲突时以文档为准并在提交中说明。
3. 用户可见变更同步 CHANGELOG.md；里程碑结束更新 ROADMAP.md 勾选状态。
4. 对应 P0 手测用例通过并记录（见迭代收口标准）。
